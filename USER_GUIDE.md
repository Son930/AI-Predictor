# 📖 User Guide

## Dashboard Overview

### Main Controls
- **Connect/Disconnect**: Connect to your MT5 broker
- **Start/Stop/Pause**: Control bot operation
- **Emergency Stop**: Immediately close all positions

### Trading Configuration
- **Symbols**: Add/remove trading pairs
- **Lot Size**: Set position sizes
- **Strategy**: Choose trading approach
- **Emotion Level**: Set risk tolerance

## Trading Strategies

### 1. Scalping
- **Best for**: High-frequency, small profits
- **Risk**: Low to medium
- **Hold Time**: Minutes to hours
- **Profit Targets**: Quick (0.5-1.5%)

### 2. Balanced
- **Best for**: Daily trading, steady growth
- **Risk**: Medium
- **Hold Time**: Hours to days
- **Profit Targets**: Target (1.5-3%)

### 3. Aggressive
- **Best for**: Trend following, larger moves
- **Risk**: High
- **Hold Time**: Days to weeks
- **Profit Targets**: Super (3-5%+)

### 4. Swing
- **Best for**: Position trading, major trends
- **Risk**: Medium to high
- **Hold Time**: Days to weeks
- **Profit Targets**: Super (3-5%+)

## Emotion Levels

### Fearful (0.7x)
- Takes profits earlier
- Smaller position sizes
- Tighter stop losses

### Cautious (0.85x)
- Conservative approach
- Balanced risk/reward
- Standard position sizing

### Standard (1.0x)
- Default settings
- Balanced approach
- No emotion modifiers

### Confident (1.15x)
- Allows profits to run
- Larger position sizes
- Wider stop losses

### Greedy (1.3x)
- Maximum profit potential
- Largest position sizes
- Widest stop losses

## Position Management

### Automatic Features
- **Stop Loss**: Placed automatically based on strategy
- **Take Profit**: Set to profit targets
- **Trailing Stop**: Moves with price movement
- **Proactive Exit**: Closes positions at profit zones

### Manual Override
- **Close Position**: Manually close any position
- **Modify SL/TP**: Adjust stop loss or take profit
- **Emergency Close**: Close all positions immediately

## Monitoring

### Real-time Data
- **Open Positions**: Current trades and P&L
- **Trade History**: Completed trades and results
- **Performance Stats**: Win rate, profit factor
- **Logs**: Detailed bot activity

### Alerts
- **Position Updates**: When trades are opened/closed
- **Error Notifications**: Connection or trading issues
- **Performance Alerts**: Unusual activity

## Best Practices

### 1. Start Small
- Begin with small lot sizes
- Test strategies on demo accounts
- Monitor performance closely

### 2. Risk Management
- Never risk more than 2% per trade
- Use appropriate emotion levels
- Monitor drawdown

### 3. Regular Review
- Check performance weekly
- Adjust strategies based on results
- Monitor market conditions

### 4. Backup
- Export configuration regularly
- Keep logs for analysis
- Document any custom settings
